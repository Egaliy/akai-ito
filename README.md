# Akai Ito — the red thread

**[akai-ito-kappa.vercel.app](https://akai-ito-kappa.vercel.app)** — concept site for an AI dating product.

[![Akai Ito](cover.jpg)](https://akai-ito-kappa.vercel.app)

*Your twin dates millions. You go on one date.*
Akai Ito builds a digital twin of you. It goes on millions of first dates, lives ten thousand lives with your best match, then books one real dinner.

**What I did:** product concept, brand, art direction, design and front-end — end to end, solo.

**How it's built**
- Scroll-driven storytelling in acts, with smooth scrolling (Lenis)
- A hand-drawn red thread that runs through the whole page
- Video scenes and an interactive simulation of the twin's dates

> This repository is a case study. The source code is private.
